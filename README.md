# Past projects

Front end web projects I designed and built between 2019 and 2021 while training in software engineering (CPISM). They are kept here as they were built, as a record of early work: plain HTML, CSS and JavaScript, with jQuery, AngularJS and Bootstrap where noted.

| Project | What it is | Built with | Live site |
|---|---|---|---|
| [Cosy Air Conditioners](cosy-air-conditioners/) | Air conditioner retail site with brand pages, reviews and a side by side product comparison tool (pick up to three units to compare) | HTML, CSS, jQuery | [View live](https://adeoluadesunloye.github.io/past-projects/cosy-air-conditioners/airconditioner.html) |
| [Farm Produce Store](farm-produce-store/) | Online store for grains, oils, spices and fresh produce, with 55+ product pages, gallery and FAQs | HTML, CSS, JavaScript | [View live](https://adeoluadesunloye.github.io/past-projects/farm-produce-store/home.html) |
| [GrubKing Cloud Kitchen](grubking-cloud-kitchen/) | Cloud kitchen ordering site with partner restaurant pages, location and menu filtering from JSON data | HTML, CSS, JavaScript | [View live](https://adeoluadesunloye.github.io/past-projects/grubking-cloud-kitchen/html/homepage.html) |
| [Muvit Carpool](muvit-carpool/) | Ride sharing and carpooling site with trip search, billing, road safety content and a PHP and MySQL sign up | HTML, CSS, AngularJS, Bootstrap, PHP, MySQL | [View live](https://adeoluadesunloye.github.io/past-projects/muvit-carpool/muvitridez.HTML) |
| [Quick Calligraphy](quick-calligraphy/) | Calligraphy learning site with lessons for children and adults, fonts and styles, and a design gallery | HTML, CSS, Font Awesome | [View live](https://adeoluadesunloye.github.io/past-projects/quick-calligraphy/index.html) |

The live versions are hosted free with GitHub Pages. Muvit's PHP sign up only works when run locally.

Cosy Air Conditioners was a group project.

## Running locally

Open the start page in a browser. Muvit's sign up needs PHP and a local MySQL database (schema in `muvit-carpool/users-table/users.sql`, connection settings in `config.php`).
